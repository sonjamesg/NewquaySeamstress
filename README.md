# Newquay Seamstress – website

Live site: **https://newquayseamstress.com** (Hostinger, `public_html`).
A static site generated by `build.py` from plain data and content files. No framework and no database.

## Where to edit things

| You want to change… | Edit this file |
| --- | --- |
| **Prices** (any item, add/remove a row or category) | `data/prices.json` |
| **Phone, email, contact name, drop-off note, opening hours, social links** | `data/site.config.json` |
| **FAQs** (question + answer, HTML allowed) | `data/faqs.json` |
| **Areas served** (town + one-line blurb) | `data/areas.json` |
| **Services** (nav label, home-page card text, which price categories a page shows) | `data/services.json` |
| **Page text** (headings, paragraphs, images, page title and meta description) | `content/pages/<page>.html` |
| Colours, fonts, spacing | `src/css/01-tokens.css` (then the other numbered CSS modules) |
| Behaviour (menu, sticky call bar, seam animation, form) | `src/js/*.js` |
| Photos | `src/img/<seo-friendly-name>.webp` (1024 px master; AVIF/WebP sizes are made for you) |

Values in `[square brackets]` in `data/site.config.json` (opening hours, Facebook/Instagram/Google links) are **unknown**: they stay hidden on the site and out of the structured data until you fill them in.
The public address is deliberately just "Newquay, Cornwall" (drop-off by arrangement).

### Page files
Each file in `content/pages/` starts with a JSON block between `---` lines (title, meta description, breadcrumb label, etc.), followed by the page's HTML.
Inside the HTML you can use shortcodes, which pull from the data files so nothing is typed twice:

| Shortcode | Output |
| --- | --- |
| `{{phone}}`, `{{email}}` | phone / email link |
| `{{call_btn btn}}`, `{{email_btn btn alt}}` | call / email buttons (with icons) |
| `{{price_table trousers}}` | guide-price table for a category in `prices.json` |
| `{{guide_note}}` | the "guide prices only" note |
| `{{from}}` / `{{from zips}}` | lowest guide price overall / in a category |
| `{{std}}`, `{{exp}}`, `{{express}}` | standard turnaround, express turnaround, express surcharge |
| `{{img name|alt text}}` (add `|eager` for the first image) | responsive AVIF/WebP picture from `src/img/name.webp` |
| `{{faqs}}` / `{{faqs 4}}` | all FAQs / the first 4 |
| `{{sidebar trousers}}`, `{{crumbs}}`, `{{people}}`, `{{service_cards}}`, `{{price_teaser}}`, `{{area_list}}`, `{{area_badges}}`, `{{enquiry_form}}`, `{{hero_logo}}`, `{{button #7b2d26}}` | page components |

## Build

One-off setup: Python 3.11+ with `pip install pillow fonttools brotli minify-html markdownify beautifulsoup4 cairosvg`, and Node 18+ with `npm install` (esbuild, svgo, lighthouse).

```bash
python3 build.py            # production build into docs/ (minified)
python3 build.py --pretty   # readable HTML
tools/check.sh              # self-check (links, titles, alts, h1s), html-validate, Schema.org validator, then production build
python3 tools/lighthouse.py # Lighthouse mobile + desktop scores for the live site
```

Preview locally: `cd docs && python3 -m http.server 8000`, then open http://localhost:8000.

## Deploy (Hostinger)

Upload the **contents** of `docs/` (including the hidden `.htaccess`) to `public_html` of the `newquayseamstress.com` website
(hPanel → File Manager, FTP, or the Hostinger API/MCP upload used for the first deploy). Then clear the website cache in hPanel.
`.htaccess` handles https + www→root redirects, 301s for retired URLs, Brotli/gzip, one-year caching for hashed assets and security headers (CSP, HSTS…).

The old GitHub Pages address (https://sonjamesg.github.io/NewquaySeamstress/) is served from the `gh-pages` branch and redirects every page to the new domain.

## How it is put together

```
build.py                 orchestrates the build
lib/config.py            loads data/*.json, shared helpers
lib/pages.py             loads content/pages/*, expands shortcodes
lib/components/          header, nav, mobile_menu, footer, cta (band + sticky call bar), price_table, contact, images, icons, seam
lib/head.py              <head>: title, meta, canonical, hreflang, Open Graph/Twitter, preloads, inline critical CSS
lib/schema.py            JSON-LD @graph (LocalBusiness/ProfessionalService, Person ×2, WebSite, WebPage types, Service + OfferCatalog, FAQPage, BreadcrumbList)
lib/outputs.py           sitemap.xml (lastmod), robots.txt, llms.txt, llms-full.txt, per-page .md, .htaccess, manifest, redirect stubs
lib/assets.py            CSS/JS bundling + minifying (esbuild), fonts, AVIF/WebP images, svgo logos, OG image, favicons
src/css/                 00-fonts … 10-price are inlined as critical CSS; 20-components and 30-animations load without blocking
src/js/                  main.js imports nav.js, reveal.js, form.js, seam.js (bundled to one deferred file)
src/fonts/               self-hosted, subset WOFF2 (Lora, Playfair Display, Pinyon Script, Special Elite)
```
